# Modelos de cenário

Os modelos usados como cenário vêm do pacote **Tanks, Military Vehicles and Field Camp**, publicado por 3DAssets.dev sob **CC0 1.0 Universal**. O uso e a modificação são livres, sem exigência de atribuição.

- Pacote e licença: https://3dassets.dev/packs/armoured-column-and-field-camp
- Manifesto: https://3dassets.dev/api/v1/packs/armoured-column-and-field-camp
- Licença CC0: https://creativecommons.org/publicdomain/zero/1.0/

Os tanques jogáveis usam os modelos procedurais próprios do projeto. Os modelos genéricos de tanque baixados durante uma tentativa anterior foram removidos porque não combinavam com o visual desejado. As peças de cenário não têm imagens de textura; o jogo agrupa suas cores em uma única malha.
